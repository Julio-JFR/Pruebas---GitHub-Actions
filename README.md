# MilOficios

Plataforma web y móvil desarrollada para conectar clientes con especialistas de manera rápida y segura.

## Tecnologías Utilizadas
* **Frontend:** Angular
* **Backend:** PHP / REST APIs
* **Base de Datos:** MySQL
* **Autenticación:** Google reCAPTCHA v2

## Descripción
Este repositorio contiene la versión de distribución del sistema MilOficios, configurado para integrarse con despliegues automatizados mediante GitHub Actions.
